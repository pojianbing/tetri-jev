# TypeSafe AI Jev 俄罗斯方块 (真 System One 决策驱动与人机对战模式)

本项目基于 [TypeSafe AI 官方指南](https://docs.typesafe.ai/introduction)，开发了一款**完全依赖 TypeSafe 官方云端 Jev (System One) 模型**自动决策的现代俄罗斯方块游戏，支持**单人演练模式**与**⚔️ 人机对战竞技模式 (Human vs Jev)**。

> ⚠️ **运行规则**：本项目已**彻底移除本地假玩降级**。必须配置有效的 TypeSafe API Key 才能调用 Jev 自动决策。

---

## 🌟 核心理念：Code + System One

在传统 LLM 开发中，让模型输出长文本再解析往往存在延迟高、格式易碎等缺陷。而 TypeSafe 的 **System One** 理念是：
1. **代码控制流程与确定性规则（Code in Control）**：由游戏引擎负责 10x20 棋盘物理、碰撞检测、行消除规则以及所有合法落点的物理计算。
2. **Jev 负责小粒度常识战略判断（Programmable Common Sense）**：对于当前方块与候选落点，打包为结构化 `state`，向 Jev 提出类型化问题（`Choice` 评选最佳落点、`Score` 评估盘面危险等级），Jev 在官方云端快速返回类型化决策、概率分布（Probabilities）与置信度（Confidence）。

## ⚔️ 人机对战模式 (Human vs TypeSafe Jev)

点击顶部导航栏的 **`⚔️ 人机对战模式`** 即可进入双人竞技场：

### 1. 绝对公平发牌 (Synchronized 7-Bag Seed)
- 人类玩家与 Jev AI 共享完全相同的方块流（镜像随机种子），双方接收到的方块类型、顺序与 Next 方块完全一致。

### 2. 垃圾行攻击与抵消机制 (Garbage Lines Attack & Cancel)
- **攻击规则**：
  - 消除 2 行（Double）：向对方发送 **1 行** 垃圾行；
  - 消除 3 行（Triple）：向对方发送 **2 行** 垃圾行；
  - 消除 4 行（Tetris）：向对方发送 **4 行** 强力垃圾行！
  - 连击（Combo）：每次连续消行追加额外攻击行。
- **缓冲与抵消（Offset）**：
  - 受到攻击时，垃圾行进入侧边红色的 **垃圾行缓冲槽 (Garbage Meter)**；
  - 若在缓冲期内自身快速消行，**优先抵消** 待接收的攻击行，剩余的攻击反弹给对方；
  - 若未能抵消，待方块锁定后，棋盘底部升起带有随机缺口的坚硬灰色砖块，迫使对手提高甚至顶出出局（Top-out KO）。

### 3. Jev 攻防态势动态博弈
- Jev 实时感知对方的堆叠高度与自身待接收的垃圾行；
- 在面临垃圾行威胁时，Jev 优先选择**紧急消行防守抵消**；在局势平稳安全时，选择**蓄力留井打出 Tetris 4 行致命反击**！

## 🚀 快速启动与体验

本地服务已在后台运行，请直接在浏览器中打开：

👉 **[http://localhost:3000](http://localhost:3000)**

### 使用步骤：
1. 打开网页 [http://localhost:3000](http://localhost:3000)；
2. 在右侧 **🔑 TypeSafe API Key (必填)** 输入框中粘贴您的密钥（获取地址：[console.typesafe.ai/keys](https://console.typesafe.ai/keys)），点击 **保存并测试**；
3. **单人演练**：点击 **`▶ 启动 Jev 云端自动游玩`** 观察 Jev 自动决策消除；
4. **人机对战**：点击顶部 **`⚔️ 人机对战模式 (Human vs Jev)`**，立即与云端 Jev 展开对决！

## 🕹️ 键盘操作说明（人类操控）

| 按键 | 功能 |
| :--- | :--- |
| **← / →** 或 **A / D** | 左右移动方块 |
| **↑ / W** | 顺时针旋转方块 |
| **↓ / S** | 软降加速下落 |
| **Space (空格)** | 硬降直接瞬间落底 |
| **C** | 暂存当前方块 (Hold) |
| **P** | 暂停 / 继续游戏 |
